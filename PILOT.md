# Virtual wardrobe pilot

- Build a ChatGPT plugin for the owner and a few invited testers. Each person has a private wardrobe.
- Aim for an outfit in the first chat. Users can upload photos of their clothes and accessories and describe what they want to wear.
- Offer optional Gmail import inside the plugin. Search a connected Gmail account when its owner asks. Show detected pieces grouped by order and let the owner select which pieces they kept. Repeating a search should preserve earlier choices and avoid duplicate items.
- When a receipt has no usable photo, use the confirmed description for styling if it identifies the piece. If it only gives a product code or similarly vague wording, ask for a photo or a short description before recommending it.
- When the wardrobe is missing a piece for an outfit, show the available combination and ask what else the person owns. Offer shopping suggestions only on request.
